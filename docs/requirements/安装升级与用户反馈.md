# 需求文档：安装升级与用户反馈

- 批次：2026-09-16-安装升级与用户反馈
- 状态：用户已授权实施（本任务对话）；对外地址等待提供，未配置时不可伪装已上线。
- 目标版本：1.1.0（本地基线 1.0.0 已提交）

## 一、总体目标

普通 Windows x64 用户无需安装开发工具即可安装看板、完成首次配置、收到更新提示并主动升级，通过微信群反馈问题。

## 二、用户故事

1. 下载带运行环境的中文安装 EXE，以当前用户权限安装；完成后打开原有看板配置向导。
2. 保留便携 ZIP 与源码入口，普通用户只看到一个推荐的安装入口。
3. 启动及后台每天至多自动检查一次公开版本信息；支持手动检查、关闭自动检查、稍后提醒。
4. 更新展示版本和摘要，点击后下载并校验安装包，交由中文安装向导完成；不静默安装。
5. 升级备份旧程序、配置与历史，正常升级保留数据；安装失败回退旧程序。网络失败不影响采集。
6. 完整卸载任务、托盘、自启、快捷方式及协议；默认保留数据，删除数据须用户明确选择。
7. 软件、README、安装完成页均能找到反馈入口；固定社区页面可更换群二维码；复制反馈模板仅含版本、系统和待填问题。
8. GitHub/Gitee 同步同一组产物，更新源优先 Gitee、GitHub 兜底；尚未建立的仓库不可编造。

## 三、非功能要求

- 不上传密钥、用量、目录或匿名使用数据；R3 遥测不在本批。
- 发布前沿用审计闸门；新增独立副本测试，不能替换真实配置或停止当前开发目录的采集。
- 新模块拆为独立文件，不继续扩张配置向导内联脚本。
- 需求、设计、批次交付/差异/验证及 CHANGELOG 同步；旧批次记录不改写。
- 实机安装、平台取数、真实群二维码等未验证项目须如实列明。
