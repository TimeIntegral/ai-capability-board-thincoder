# 连接与发布隔离

2026-09-17：用户采纳简化连接、分离开发与发布方案，目标版本 1.3.0。

## 连接体验

默认入口：看板开始配置 → 本机连接窗口 → 勾选平台、按需填 Key → 保存并验证。无需选择目录，无需额外安装 ThinCoder。看板上的「开始配置」直接开这个窗口（`aiquotaboard://connect`）；页面里的旧网页向导已于 2026-09-17 整块移除（见变更记录）。

按平台聚焦（2026-09-17 新增契约）：看板卡片上的「启用平台」发 `aiquotaboard://connect?platform=codex|deepseek|glm`，本机窗口只渲染该平台（标题与内容都只有它），保存只写这一家的开关，其余平台原样保留；不带 `platform` 或值不在白名单内 = 三家都显示（老行为）。
链路：页面 → `运行协议.vbs` → `程序/tools/connections.mjs --platform=<平台>` → `程序/tools/connections.ps1 -Platform <平台>`（协议侧已于 2026-09-17 补齐 `platform` 透传，见变更记录）。

提醒时机（2026-09-17 新增）：连接窗口底部多一段「提醒时机」——四条最常改的提醒线（`codex5hWarn` / `codexWeekWarn` / `dsLow` / `glmLow`）用数字控件直接改，保存时随同一份载荷写进 `config.json` 的 `thresholds`。
现状值由 `程序/tools/connections.mjs` 经环境变量 `BOARD_THRESHOLDS` 注入（不进命令行、不进 URL、不落盘；取不到就回退内置默认值）；窗口只写它画出来的那几条，聚焦模式不碰其它家；紧急阈值（`*Critical`）与其余参数仍走 `程序/tools/edit-config.mjs`。
窗口高度随这一段收紧并逐档复测（含标题栏，上限 = 768 屏高 − 48 任务栏）：完整窗口 694 → 保存后 716、聚焦 Codex 534 → 556、聚焦余额 554 → 576——1366×768 笔记本上完整可见可点。

本机窗口复用已有凭据；留空保留旧值，显式粘贴时更新本机 secrets.json，不改 ThinCoder 配置。页面不接触密钥；进程间经标准输入传递，不进入参数、URL、日志。损坏的已有文件拒绝覆盖。配置其他字段保留。

Codex 使用本机登录；DeepSeek / GLM 只承诺现有采集器支持的 API 余额，不承诺聊天订阅或 Coding Plan 额度。配置保存后验证各家连接，一家失败不影响其他家；自动采集安装失败要明确说明，不能假报完成。开发模式只试采，不注册系统集成。

## 开发与发布

开发目录供 Agent 修改，完成检查后保存代码提交。代码提交不等于发布。日常版使用默认安装目录，历史和配置留在日常版目录。

准备发布：干净提交 → 独立 worktree → 自动测试及审计 → 构建安装包与便携包 → 生成候选快照记录。继续开发不修改既有候选包。上传和公开发布是单独动作。

开发目录检测以 .git 文件或目录存在为准，禁止注册后台任务、安装更新。此前已指向源码目录的任务不会自动迁移；实际安装独立发行版后，由其注册任务和桌面入口。迁移历史前应备份，不能仅靠本次代码隔离推断旧任务已切换。
