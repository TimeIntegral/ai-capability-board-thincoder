# 待办台账

本文件是本项目的**需求池**与**技术待办**清单，同时作为对外公开的路线图。条目一行一条。

- **需求池**：面向用户的功能诉求，按批次推进（一个批次 = 一份需求档 + 设计档 + 批次档）
- **技术待办**：工程侧的欠账与改进，每条带一个触发条件

**状态取值**：`待讨论` / `待设计` / `在途` / `待核销`；已完成的移入下方归档区。

**技术待办的触发**：`归批（<批名>）` / `条件（<条件句>）` / `认账不排期`。
